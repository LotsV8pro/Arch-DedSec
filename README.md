## ◈ About

Arch-DedSec was the original version of what became **Lotus-Arch**. It provided a complete Arch Linux desktop environment with Hyprland Lua configuration and a purple DedSec-themed aesthetic.

This repo is preserved for reference. All active development has moved to [Lotus-Arch](https://github.com/LotsV8pro/Lotus-Arch), which includes:

- Full rebrand from DedSec → Lotus
- Same core Hyprland Lua config
- Expanded audio pipeline (virtual mic, HeSuVi 7.1, Arctis Nova 5)
- Interactive installer with per-app granularity
- Matching themes for Spicetify and Vencord
